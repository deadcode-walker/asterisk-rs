# Core beliefs

- Optimize the repository for legibility to a capable newcomer and agent.
- Preserve validated knowledge in types and durable artifacts instead of repeated instructions.
- Prefer one boring implementation, explicit ownership, and short feedback loops.
- Add a dependency, service, abstraction, or build system only for a measured gap.
- Promote repeated review guidance into checks or canonical docs, then remove the prose duplicate.
- Treat entropy as continuous maintenance: small targeted cleanup beats periodic rewrites.
